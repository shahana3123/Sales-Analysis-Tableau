# Sales Analysis Dashboard – Tableau

## About the Project

This project is a Tableau dashboard created to analyze sales performance across different product categories and regions.

## Tools Used

- Tableau
- Excel

## Dashboard Features

- Category-wise Profit Analysis
- Regional Sales Analysis
- Sales Performance Analysis

## Dashboard

The dashboard provides a visual overview of sales performance across different categories and regions.

## Key Skills

- Data Analysis
- Data Visualization
- Dashboard Design
- Tableau
- Excel

## Project Purpose

The purpose of this project is to practice data analysis and create an interactive dashboard using Tableau.
